# Support

## Documentation

Start with the guides at [fastplace.dev](https://fastplace.dev) — getting
started, the database layer, authentication, AI, background jobs, testing,
deployment, and versioning. The [README](README.md) holds the architectural
overview and a quickstart.

## Bugs and feature requests

Open a [GitHub issue](https://github.com/fastplace-dev/fastplace.dev/issues).
The issue templates will ask for a reproduction and your environment — the
more complete they are, the faster the triage.

## Security

Do **not** use public issues for anything security-related. Follow
[SECURITY.md](SECURITY.md) and use GitHub's private vulnerability reporting.

## Questions and discussion

There is no chat or forum channel yet; GitHub issues are the routing point for
now. Commercial support is not offered at this time.
